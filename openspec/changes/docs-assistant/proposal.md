# Proposal

## Why

Пользователь приложения хочет спросить «как это работает» своими словами и получить ответ
по описанию самого приложения. Для этого появляется необязательный сервис `wallet-docs`
(см. change `wallet-docs-assistant` в wallet-infra): он ищет по OpenSpec-спекам и отвечает.
Для Android он отдаёт только то, что относится к самому приложению; какие именно спеки
доступны, решает сервер по токену, клиент ничего не выбирает.

## What Changes

- В экран «Ещё» добавляется пункт «Вопрос по приложению». Он виден только после ответа `200`
  на `GET /api/docs/status`; при любом другом ответе или без сети его нет, остальной экран
  не меняется.
- Новый экран «Вопрос по приложению»: поле «Ваш вопрос…», кнопка «Спросить», ответ текстом
  и список источников (названия разделов спек). Диалог не хранится: один вопрос — один ответ.
- Запросы идут через wallet-gateway: `GET /api/docs/status`, `POST /api/docs/ask`
  (контракт — в `openapi.yaml` wallet-docs). Клиент не передаёт, кто он: сервер берёт
  `platform` из токена.
- Тексты — в `values/strings.xml` (английский) и `values-ru/strings.xml` (русский).

## Capabilities

### New Capabilities
- `docs-assistant`: вход в справочного помощника из «Ещё», скрытие при недоступном сервисе,
  экран вопроса и ответа, поведение при ошибках и без сети.

### Modified Capabilities

## Impact

- **android-wallet**: экран «Ещё» (`MoreActivity`), новая Activity вопроса, клиент сети рядом
  с `AiApiClient`, строки ru/en, юнит-тесты разбора ответа и логики видимости.
- **Другие сервисы**: google-auth (`docs-audience`, токен с `aud` ∋ `wallet-docs`),
  wallet-gateway (`docs-route`), wallet-docs. Выкатываются раньше клиента.
- Совместимость со старыми клиентами не требуется: пока в токене нет `wallet-docs`, пункт скрыт.
