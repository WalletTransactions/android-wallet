# Design

## Context

Приложение офлайн-первое: локальная SQLite, сеть только в `sync/` через общий `OkHttpClient` и
`AuthSession`. Функции ИИ уже скрываются по ответу `GET /api/ai/status`: экран «Ещё»
(`MoreActivity`) запрашивает его через `AiApiClient`. Для docs берём тот же приём. См. proposal.md.

## Goals / Non-Goals

**Goals:**
- Пункт в «Ещё», появляющийся только при `200` на `/api/docs/status`.
- Экран «один вопрос — один ответ» с источниками и понятными ошибками.

**Non-Goals:**
- Диалог с историей, хранение вопросов, офлайн-кэш ответов.
- Выбор области документации: её определяет сервер по `platform` и `role` в токене.
- Совместимость со старыми версиями клиента.

## Decisions

**D1. Статус проверяется при открытии «Ещё», по образцу ИИ.** Запрос асинхронный: пункт
скрыт по умолчанию и появляется после `200`. Результат держится в памяти процесса, не в
базе — как у `features` ИИ. Альтернатива «кэшировать на диск» отвергнута: при выключенном
сервисе пункт сохранялся бы до следующей проверки.

**D2. Отдельный клиент `DocsApiClient` рядом с `AiApiClient`.** Использует общий
`OkHttpClient` и `AuthSession`, ходит только на `/api/docs/*` через гейтвей. Общей
абстракции с ИИ не вводим: два метода, один формат ошибок.

**D3. Новая Activity, а не диалог.** Ответы длинные, нужна прокрутка и клавиатура; тот же
подход, что у экранов «Ещё». Состояние (вопрос, ответ) — в Activity, при повороте
сохраняется в `onSaveInstanceState`, при закрытии теряется (по спеке).

**D4. Клиент не передаёт `client` в запросе.** Сервер берёт `platform` из токена. Альтернатива
«поле в теле» отвергнута: лишняя поверхность, и значение пришлось бы доверять клиенту.

**D5. Сообщения об ошибках — по классам статуса.** Сеть, `401`, `400`, `404`/`502`/`503`
сопоставляются с тремя строками ресурсов. Текст ошибки `400` берётся из тела сервиса.

**Правки вне android-wallet:** нужны google-auth (`docs-audience`), wallet-gateway
(`docs-route`) и сервис wallet-docs. Парных правок на вебе нет, кроме собственного
change `docs-assistant` в wallet-web.

**Офлайн и отказ сервера.** Без сети экран «Ещё» открывается сразу, пункта нет; на уже
открытом экране вопроса ошибка не закрывает его, вопрос остаётся в поле.

## Risks / Trade-offs

- [Старый токен без `wallet-docs`: `401` на статусе] → пункт скрыт; после обновления токена
  (до 15 минут) появится при следующем открытии «Ещё».
- [Ответ приходит на языке документации] → допущение: спеки на русском; при английском
  телефоне пользователь видит русский ответ. Перевод вне объёма.
- [CRLF-файлы и жёсткая проверка текстов в CI] → строки только через ресурсы; файлы
  правятся с сохранением CRLF.
