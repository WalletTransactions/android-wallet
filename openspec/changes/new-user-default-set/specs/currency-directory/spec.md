# Spec Delta

## ADDED Requirements

### Requirement: Название общей валюты на языке телефона
Общая валюта SHALL показываться в списке «Валюты», в пикерах валюты и в
форме валюты под названием, которое Android даёт её коду ISO на текущем
языке телефона. Если Android код не знает, показывается название с сервера.
Своя валюта SHALL показываться под своим сохранённым названием. Хранимое
название общей валюты не меняется.

#### Scenario: Общая валюта на английском телефоне
- **WHEN** общая валюта `RSD` с сервера называется «Сербский динар», язык телефона английский
- **THEN** в списке «Валюты» и пикерах она «Serbian Dinar»

#### Scenario: Своя валюта с известным кодом
- **WHEN** у пользователя своя валюта с кодом `USD` и названием «Доллары нал»
- **THEN** она везде показывается как «Доллары нал»

#### Scenario: Неизвестный код
- **WHEN** общая валюта с кодом `USDT`, который Android не знает, называется на сервере «Tether»
- **THEN** она показывается как «Tether»
