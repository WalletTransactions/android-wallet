# Spec Delta

## Purpose

Встроенный набор, которым приложение заполняет пустую базу при чистой
установке и полной очистке: что в нём есть, как помечаются его строки и что
происходит с уже установленными приложениями.

## ADDED Requirements

### Requirement: Набор без личных данных
Набор чистой установки SHALL содержать только общие категории, системные
категории `Transfer` и `Transfer commission`, иконки категорий, валюты с
флагами и валютные пары. Набор SHALL NOT содержать кошельков, курсов и
названий, относящихся к конкретному человеку, банку или месту.

#### Scenario: Чистая установка
- **WHEN** приложение установлено впервые и открыто без входа
- **THEN** в списке категорий общие категории набора и `Transfer`, `Transfer commission`; кошельков нет; на экране «Курсы валют» пары набора без курсов

#### Scenario: Личные строки прежнего набора
- **WHEN** приложение установлено впервые
- **THEN** категорий «Квартира Рисан», «Черногорские Внж», «От Саши» и кошельков «Альфа Саша Руб», «Баба О» нет

### Requirement: Язык набора
Категории набора SHALL заводиться с русскими именами, если язык телефона
при посеве русский, и с английскими при любом другом языке. Валюты набора
SHALL получать название, которое Android даёт коду ISO на том же языке;
если Android код не знает — имя из набора. Системные `Transfer` и
`Transfer commission` заводятся с этими именами при любом языке. Смена
языка телефона после посева имена не меняет.

#### Scenario: Русский телефон
- **WHEN** чистая установка на телефоне с русским языком
- **THEN** категории «Продукты», «Такси», валюта `EUR` называется «евро»

#### Scenario: Английский телефон
- **WHEN** чистая установка на телефоне с немецким языком
- **THEN** категории «Groceries», «Taxi», валюта `EUR` называется «Euro»

#### Scenario: Смена языка после установки
- **WHEN** набор посеян на русском, затем язык телефона сменён на английский
- **THEN** категории по-прежнему «Продукты», «Такси»

### Requirement: Метка «из набора»
Каждая категория, валюта и пара, заведённая из набора, SHALL быть помечена
«из набора». Метка SHALL сниматься, когда пользователь меняет у строки
название, иконку, код или символ. Метка хранится только на телефоне и на
сервер не отправляется.

#### Scenario: Переименование категории набора
- **WHEN** пользователь переименовал категорию набора «Кафе» в «Кофейни»
- **THEN** у «Кофейни» метки «из набора» нет

#### Scenario: Операция без правки категории
- **WHEN** пользователь внёс операцию по категории набора «Такси», не меняя саму категорию
- **THEN** метка «из набора» у «Такси» остаётся

### Requirement: Обновление приложения не меняет базу
Обновление приложения с новым составом набора SHALL NOT добавлять, менять
или удалять строки уже существующей базы. Новый состав получают только
чистая установка и полная очистка базы с пересевом.

#### Scenario: Новая категория в наборе
- **WHEN** в новой версии в набор добавлена категория «Подписки», а у пользователя база прежней версии
- **THEN** после обновления категории «Подписки» у пользователя нет

#### Scenario: Полная очистка с пересевом
- **WHEN** пользователь выполнил «Полная очистка базы» с пересевом
- **THEN** база заполнена текущим набором, строки помечены «из набора»

### Requirement: Существующие строки без метки
При обновлении базы до версии с меткой все уже существующие категории,
валюты и пары SHALL считаться не «из набора».

#### Scenario: Обновление базы автора
- **WHEN** приложение с базой, заполненной прежним личным набором, обновлено до версии с меткой
- **THEN** ни одна строка не помечена «из набора», и при подключении к кошельку ни одна не удаляется как нетронутая строка набора
