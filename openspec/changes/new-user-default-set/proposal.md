# Proposal

## Why

Встроенный набор `app/src/main/assets/seed.json`, которым заполняется пустая
база, — слепок личных данных автора: 46 кошельков («Альфа Саша Руб», «Баба
О»), 91 категория («Квартира Рисан», «Черногорские Внж»), 14 валют его поездок
и курсы на 15.01.2024–2026. Все строки сеются с `dirty = 1`, поэтому при первом
синке новый человек отправляет чужие кошельки в свой кошелёк на сервере, а
переустановка с входом в уже наполненный кошелёк возвращает туда удалённые
когда-то категории. Приложение работает и без входа, так что набор нужен,
но он должен быть общим для новых людей и не мешать при подключении к
существующему кошельку.

## What Changes

- **Новый набор** вместо личного: общие категории на русском, системные
  `Transfer`/`Transfer commission`, ходовые валюты и пары, иконки категорий
  и флаги. Курсов в наборе нет. Личные кошельки и категории удаляются.
- Строки, заведённые из набора, помечаются «из набора» до первой правки
  пользователем. Метка локальная, на сервер не уходит.
- **Язык набора:** категории в `seed.json` — с русским и английским именем;
  при посеве берётся русское, если язык телефона русский, иначе английское.
  Названия валют набора — названия Android по коду ISO на том же языке.
  Общие валюты с сервера показываются названием Android на текущем языке
  телефона. Готовит почву для change `android-i18n`.
- **Первое подключение** телефона к кошельку на сервере (первый синк после
  входа на базе, которая ещё ни разу не синкалась, — в том числе после
  переустановки и полной очистки):
  - загрузка идёт **до** отправки;
  - пришедшая валюта, пара или счёт с тем же ключом (код валюты, символ пары,
    имя счёта), что у неотправленной локальной строки, заменяет её: локальная
    строка берёт uuid и поля серверной, ссылки на неё сохраняются;
  - если кошелёк на сервере уже не пуст, нетронутые строки набора без
    операций удаляются с телефона и не отправляются;
  - если на телефоне есть операции, внесённые без входа, приложение один раз
    спрашивает: перенести их в кошелёк или удалить с телефона.
- Если кошелёк на сервере пуст, набор отправляется целиком и становится его
  категориями.
- Набор применяется к кошельку один раз: изменения набора в новых версиях
  приложения достаются только новым установкам.
- Общих категорий на сервере нет и не появляется; сервер не меняется. Новый
  человек, который начал с веба, получает пустой кошелёк.

## Capabilities

### New Capabilities
- `starter-set`: встроенный набор чистой установки — состав, метка «из
  набора», поведение при обновлении и очистке базы.
- `ledger-connection`: первое подключение телефона к кошельку на сервере —
  принятие серверных строк по ключу, судьба строк набора, вопрос об
  офлайн-операциях.

### Modified Capabilities
- `sync-run`: «Состав прохода» — при первом подключении загрузка до
  отправки, новый исход «ждёт решения».
- `currency-directory`: название общей валюты — на языке телефона.

## Impact

- `app/src/main/assets/seed.json` (новый состав), `Data/WalletFillData.java`
  (метка «из набора», без курсов), `Data/WalletDbHelper.java` (v88: колонка
  метки у `account`, `currency`, `currency_pair`), `Data/WalletContract.java`,
  `Data/WalletDbCRUD.java` (снятие метки при правке), язык посева и
  название валюты по ISO (`java.util.Currency`) в списке валют и пикерах.
- `sync/SyncRunner.java` (порядок прохода при подключении, исход),
  `sync/SyncEngine.java` (принятие по ключу при загрузке, шаг подключения),
  `AppSettings.java` (признак «идёт подключение»), диалог на главном экране.
- Юнит-тесты в `app/src/test` (сид, подключение, принятие по ключу),
  `docs/ARCHITECTURE.md`.
- Сервер (wallet-api, wallet-web, wallet-telegram) не меняется. Наполнение
  общего справочника валют на сервере — работа администратора, не этого
  change: без общих валют валюты набора уходят в кошелёк как свои.
