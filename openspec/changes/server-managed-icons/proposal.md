# Proposal

## Why

Каждый синк телефон заливает на сервер свои иконки: байты в `POST
/sync/blobs`, строку `icon` в `POST /sync/push`. Это самая тяжёлая и самая
хрупкая часть прохода (инцидент 2026-10-11: обрыв на одной из 144 иконок
через Tailscale-relay), а вебу эти иконки не нужны. Теперь иконки ведёт
администратор на сайте (парные change `wallet-api: server-managed-icons` и
`wallet-web: server-managed-icons`), телефон их только скачивает. Свои
иконки, добавленные из галереи, остаются только на телефоне.

## What Changes

- **BREAKING (поведение синка):** телефон больше не отправляет иконки — ни
  строки `icon` в `POST /sync/push`, ни байты в `POST /sync/blobs`. Загрузка
  иконок (`GET /sync/pull` + `GET /sync/blobs/{sha256}`) не меняется.
- Иконка на телефоне получает признак происхождения: **с сервера** (пришла
  через pull или уже была отправлена раньше) или **своя локальная**
  (добавлена из галереи и ни разу не уходила на сервер). Миграция БД v84
  размечает существующие иконки по `dirty`.
- При отправке счёта или валюты, у которых своя локальная иконка, на сервер
  уходит иконка-заместитель с сервера: с той же картинкой, иначе с тем же
  именем, иначе общая `unknown`. Локально у счёта остаётся своя иконка, и
  pull с этим же заместителем её не затирает.
- Если с сервера приходит иконка с именем, занятым своей локальной, своя
  переименовывается (` (своя)`), серверная добавляется.
- Иконки с сервера на телефоне только для просмотра: в диалоге иконки нет
  правки и удаления, вместо них — подсказка. Свои локальные — как сейчас.

## Capabilities

### New Capabilities
- `icon-sync`: как иконки попадают на телефон и уходят (не уходят) с него:
  происхождение иконки, заместители при отправке, конфликты имён при
  загрузке, доступность правки.

### Modified Capabilities
- `sync-run`: в «Состав прохода» уточняется, что отправка локальных
  изменений не включает иконки, а частичный исход больше не возникает из-за
  незалитых иконок.

## Impact

- Код: `sync/SyncEngine.java` (убрать `collectDirtyIcons`/`ensureBlobUploaded`
  из push, подстановка заместителя в `currency`/`account`, защита локальной
  иконки и разрешение конфликта имени в pull), `Data/WalletDbHelper.java`
  (v84, колонка `icon.origin`), `Data/WalletContract.java`,
  `Activities/IconEditDialog.java`, модель `Icon`.
- Тесты: `SyncEngineDeferIconTest` переписывается (откладывания из-за иконок
  больше нет), новые юнит-тесты заместителя и конфликта имён.
- `schema/table/icon.sql`, `docs/ARCHITECTURE.md`.
- Сервер: правок для этого change не нужно — wallet-api продолжает принимать
  `icon` от старых версий; админские ручки — в его change.
