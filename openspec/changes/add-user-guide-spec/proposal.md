# Proposal

## Why

Справка по системе (`wallet-docs`) отвечает по описанию, написанному для
разработчиков: в спеках `android-wallet` эндпоинты, `uuid`, `operationId`,
идемпотентность. Пользователю Android справка видна только по репозиторию
`android-wallet` вида `spec`, поэтому на вопрос «Как добавить трату?» она
пересказывает `POST /api/ai/jobs` и `kind: parse_expense`, а не говорит «нажмите
«+», выберите «Расход»…». Для веба эта же проблема решена спекой `user-guide` в
`wallet-web` (change `add-user-guide-spec` там же); Android она не видна, потому что
его область справки — только `android-wallet`.

## What Changes

- Новая спека `user-guide` в `android-wallet` — пользовательские сценарии простым
  языком: один вопрос пользователя — одно требование, шаги названы так, как кнопки
  и пункты меню подписаны в приложении, факт для пользователя стоит первым, а
  предложение с `SHALL` — последним.
- Охват: добавить трату или доход вручную; записать трату словами; перевести деньги
  между своими кошельками; записать заём и возврат долга; загрузить выписку банка;
  посмотреть остатки по кошелькам; посмотреть, куда уходят деньги; сменить период;
  сменить валюту эквивалента; повторяющиеся операции; напоминание вносить операции;
  работа без интернета и синхронизация; вход в аккаунт и подключение Telegram;
  выгрузка и загрузка данных; код доступа; язык; «Вопрос по приложению».
- Требование к языку ответов: без названий запросов, полей и идентификаторов.
- Поведение приложения не меняется: код, экраны и тесты не трогаются.

## Capabilities

### New Capabilities
- `user-guide`: пользовательские сценарии работы с приложением Android и ответы справки на типовые вопросы обычного пользователя, простым языком и с названиями элементов интерфейса.

## Impact

- Только `android-wallet/openspec/specs/` (новая спека после синка). Код `app/`, ресурсы и `docs/` не меняются: ни один экран не меняется.
- Чанки новой спеки попадают в индекс `wallet-docs` при заливке индекса репозитория `android-wallet`; область `platform = android` его видит, веб — нет (у веба только `wallet-web` и `wallet-web-eqdefault`), Telegram и MCP видят.
- Правок `wallet-docs`, `wallet-gateway` и других сервисов не требуется.
