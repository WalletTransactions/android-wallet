# Spec Delta

## MODIFIED Requirements

### Requirement: Состав прохода
Проход синка SHALL выполнять по порядку: обновление сессии, отправку своих
иконок (только при включённой настройке и разрешающем флаге сервера, см.
`icon-upload`), отправку локальных изменений (`POST /sync/push`, wallet-api),
загрузку изменений (`GET /sync/pull`, wallet-api), чистку локальных удалённых
строк. Из ответа загрузки SHALL запоминаться `capabilities.icon_upload`.
Во время подключения к кошельку (см. `ledger-connection`) загрузка SHALL идти
до отправки, а между ними выполняются шаги подключения. Без включённой
настройки отправка локальных изменений не включает иконки (см. `icon-sync`).
Итог прохода — один из исходов: успешно, частично (часть строк не отправлена),
ждёт решения (подключение ждёт ответа на вопрос об операциях без входа), нет
сессии, нужен повторный вход, нет сети, ошибка — с журналом изменений и
причиной для ошибок. Причина исхода «нет сети» SHALL браться из «Причины сетевой
ошибки» (`server-account`). Отказ сервера принимать иконки и сбой отправки отдельной
иконки SHALL NOT приводить к исходам «частично» и «ошибка».

#### Scenario: Нет сессии
- **WHEN** пользователь не входил в аккаунт
- **THEN** проход завершается исходом «нет сессии» без обращения к wallet-api

#### Scenario: Сервер недоступен
- **WHEN** сервер не ответил вовремя при отправке изменений
- **THEN** проход завершается исходом «нет сети» с причиной «Сервер не ответил вовремя. Проверьте сеть и повторите.» (см. «Причина сетевой ошибки» в `server-account`), неотправленные строки остаются к следующему проходу

#### Scenario: Много своих иконок на медленной сети
- **WHEN** на телефоне 144 своих иконки, сеть медленная, настройка отправки выключена (по умолчанию), других изменений нет
- **THEN** проход не делает запросов загрузки иконок и завершается исходом «успешно»

#### Scenario: Сервер запретил иконки
- **WHEN** настройка включена, а сервер отвечает отказом `icon_upload_disabled`
- **THEN** настройка выключается, проход завершается исходом «успешно»

#### Scenario: Загрузка не удалась
- **WHEN** загрузка изменений завершилась ошибкой
- **THEN** чистка локальных удалённых строк в этом проходе не выполняется

#### Scenario: Подключение: загрузка первой
- **WHEN** первый проход после входа на базе, которая ещё не синкалась
- **THEN** запрос `GET /sync/pull` выполняется раньше первого `POST /sync/push`

#### Scenario: Подключение ждёт решения
- **WHEN** во время подключения показан вопрос об операциях без входа, пользователь не ответил
- **THEN** проход завершается исходом «ждёт решения», `POST /sync/push` не выполнялся
