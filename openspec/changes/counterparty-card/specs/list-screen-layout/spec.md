## MODIFIED Requirements

### Requirement: Экран «Контрагенты»
Экран «Контрагенты» SHALL иметь в блоке фильтра поле «Поиск по названию»; нижняя панель SHALL
содержать кнопку «+ Новый» и кнопку «Из контактов». Тап по строке контрагента SHALL открывать его карточку
сразу, без диалога действий (`debts`, «Карточка контрагента»). Правила поиска и архивных
контрагентов остаются прежними (`debts`).

#### Scenario: Добавление с любого места списка
- **WHEN** список контрагентов прокручен вниз
- **THEN** кнопки «+ Новый» и «Из контактов» видны без прокрутки вверх

#### Scenario: Тап по контрагенту
- **WHEN** пользователь нажимает на строку контрагента
- **THEN** открывается карточка контрагента, диалога действий нет
