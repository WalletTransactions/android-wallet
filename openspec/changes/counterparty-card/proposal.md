# Proposal

## Why

Тап по контрагенту на экране «Контрагенты» открывает диалог из трёх-четырёх пунктов (переименовать,
в архив, открыть контакт, удалить). Данные при этом богаче интерфейса: у контрагента уже есть
комментарий и иконка (`counterparty.comment`, `icon_uuid`, они синхронизируются и импортируются из
JSON), но задать их нельзя, а иконка нигде не показывается. Займы человека лежат на другом экране
(«Долги»), привязать контакт можно только при создании. Карточка собирает это в одном месте, по
образцу карточки займа.

## What Changes

- Тап по строке на экране «Контрагенты» **сразу открывает карточку контрагента**; диалога действий
  нет.
- Карточка контрагента: иконка, имя, комментарий, блок контакта, итог по займам и список займов,
  действия «В архив / Из архива» и «Удалить» (правила прежние).
- Иконка и комментарий редактируются в карточке; иконка выбирается из библиотеки иконок.
- Контакт телефона можно **привязать, перепривязать и отвязать** из карточки (системный выбор
  контакта, без разрешения на чтение контактов).
- Тап по займу в карточке открывает карточку займа.
- Без изменений: список «Контрагенты» (поиск, архивные, «+ Новый», «Из контактов»), правила уникальности
  имени и удаления, структура синка.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `debts`: новое требование «Карточка контрагента»; правки «Контрагент» (комментарий и иконка
  редактируются) и «Связь контрагента с контактом телефона» (привязка и перепривязка из карточки).
- `list-screen-layout`: «Экран «Контрагенты»» — тап по строке открывает карточку.

## Impact

- Код: `Activities/CounterpartiesActivity` (тап открывает карточку, диалог действий уходит),
  новая `Activities/CounterpartyCardActivity` и её раскладка, `Data/WalletDbCRUD` (смена иконки
  контрагента), `AndroidManifest.xml`, строки ресурсов.
- Другие сервисы не затрагиваются: `counterparty` уже синхронизирует имя, комментарий, иконку и
  признак архива; ключ контакта остаётся локальным.
- Документация: `docs/ARCHITECTURE.md` (новый экран).
