# Design

## Context

- Состояние текстов — proposal.md, «Why». Больше всего зашитых строк:
  `sync/SyncEngine.java` (94, журнал синка), `ai/AiTexts.java` (63),
  `RecurringOperationActivity` (42), `IntegrationsActivity` (41),
  `StatementImportActivity` (35), `LockActivity` (35), `TransactionActivity` (33).
- AppCompat 1.6.1, minSdk 27, targetSdk 34.
- Robolectric-тесты сейчас проверяют русские тексты и проходят, потому что
  `values/` — русский.
- OpenSpec-спеки приводят тексты интерфейса дословно по-русски.

## Goals / Non-Goals

**Goals:**
- Ни одного зашитого текста интерфейса в Java и layout, и CI это держит.
- Английский интерфейс, на котором не видно русских текстов приложения.

**Non-Goals:**
- Перевод текстов с сервера: ошибки wallet-api, ответы wallet-ai — как
  пришли; язык ответов ИИ — работа wallet-ai.
- Перевод данных пользователя и имён иконок.
- Форматы дат и чисел — остаются прежними.
- Выбор языка внутри приложения (есть системный на Android 13+).
- Языки, кроме русского и английского.
- wallet-web, wallet-telegram.

## Decisions

### D1. Порядок: вынос → перевод → смена базового языка

```
 stage 1: extract   values/ = ru            behaviour unchanged, tests green
 stage 2: translate values-en/ = en         en phones get English
 stage 3: swap      values/ = en,           any non-ru language -> English
                    values-ru/ = ru
```

Вынос идёт по экранам и сливается кусками: каждый PR не меняет поведение
русского интерфейса, тесты остаются зелёными. Перевод — после выноса всего
экрана, иначе на английском телефоне получается смесь. Смена базового
языка — последней, когда `values-en/` полон: до неё человек с немецким
телефоном видит русский, после — английский.

*Альтернатива:* сразу `values/` = английский. Отвергнута: каждый PR выноса
ломал бы тесты с русскими текстами и требовал бы перевода в том же PR.

### D2. Что выносится, а что нет

Выносится всё, что видит пользователь. Не выносятся: логи (`Log.*`),
тексты исключений для разработчика, SQL, имена ключей JSON, имена
системных категорий в базе и синке, тексты, уходящие на сервер как
данные (запросы к wallet-ai из `ai/` — их язык задаёт протокол wallet-ai,
не интерфейс). Такие строки при выносе помечаются комментарием `// not UI`,
чтобы проверка (D5) их пропускала.

### D3. Склейки и окончания

`"Удалить пару " + symbol + "?"` → `getString(R.string.pair_delete_q, symbol)`.
Ручной подбор окончаний → `getQuantityString` + `<plurals>`; для русского
формы `one/few/many/other`.

### D4. Системные категории

Показываемое имя счёта — одна функция слоя данных: при `system_kind`
TRANSFER / TRANSFER_COMMISSION — строка ресурса, иначе хранимое имя. Push,
поиск по имени и сопоставление при синке пользуются хранимым именем.

### D5. Проверка зашитых текстов

`ci/check_hardcoded_text.sh`: кириллица в строковых литералах Java вне
комментариев, `Log.*` и строк с `// not UI`, и кириллица в атрибутах
`android:text|hint|title|contentDescription` layout/menu, не начинающихся с
`@`. Сначала — список исключений по файлам, который сокращается с каждым
вынесенным экраном; в конце — пустой. Запуск в `ci/run_unit_tests.sh` и шагом
GitHub CI. Android lint `HardcodedText` не подключаем: lint в CI не запускается, а
атрибуты layout/menu проверяет тот же скрипт.

### D6. Тесты и язык

С этапа 3 — `src/test/resources/robolectric.properties` с
`qualifiers=ru`: существующие тесты продолжают проверять русские тексты
без правок. Тесты английского — явным `@Config(qualifiers = "en")`.

### D7. Язык приложения в системе

`res/xml/locales_config.xml` (`ru`, `en`) и `android:localeConfig` в
манифесте; на Android 13+ система сама показывает приложение в «Языках
приложений». Для Android 8–12 — только язык телефона.

### D8. Тексты спек

Спеки по-прежнему приводят русский текст как эталон. Английский — перевод
в `values-en/`, в спеках не дублируется.

**Правка в других сервисах:** не нужна.

### D9. Без сети

Язык не зависит от сети и сервера: все тексты — ресурсы APK.

## Risks / Trade-offs

- [Большой объём ручной правки по 125 файлам] → по экрану на PR,
  проверка D5 не даёт вернуться назад.
- [Английский перевод с ошибками] → вычитка переводом по экрану, тексты в
  одном файле `values-en/strings.xml`.
- [Длинные английские строки не влезают в кнопки и заголовки] → ручная
  проверка каждого экрана на английском.
- [Пропущенный в `values-en/` ключ молча покажет русский до этапа 3] →
  lint `MissingTranslation` как ошибка с этапа 2.

## Migration Plan

Этапы D1 — отдельными PR. Данные и база не меняются; откат — предыдущая
версия APK.
