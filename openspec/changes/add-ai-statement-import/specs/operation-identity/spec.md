# Spec Delta

## Purpose

Операция с uuid, назначенным заранее (строка импорта выписки): окно операции
создаёт её с этим uuid или открывает уже существующую. На телефоне не больше
одной операции на uuid, иначе после синка телефон и сервер разойдутся.

## ADDED Requirements

### Requirement: Новая операция с заданным uuid
Окно операции, открытое с заданным uuid, SHALL сохранять расход с этим uuid.
У перевода этот uuid SHALL получать основная проводка (списание с
кошелька-источника); вторая нога и комиссия получают свои uuid.

#### Scenario: Расход из строки выписки
- **WHEN** окно открыто с uuid `5b1e…` и пользователь сохраняет расход 450,00
- **THEN** в базе телефона операция 450,00 с uuid `5b1e…`

#### Scenario: Пользователь сменил вид на перевод
- **WHEN** окно открыто с uuid `5b1e…`, пользователь сделал перевод между кошельками в разных валютах и сохранил
- **THEN** проводка списания имеет uuid `5b1e…`, вторая нога — другой uuid

### Requirement: Существующая операция открывается на правку
Если в базе телефона уже есть живая операция с заданным uuid, окно SHALL
открыть её на правку («Изменение операции»), а не создавать новую. Если
операция с этим uuid удалена, сохранение SHALL восстановить ту же строку с
новыми полями.

#### Scenario: Повторный тап по записанной строке
- **WHEN** операция с uuid `5b1e…` уже записана и пользователь снова открывает окно с этим uuid
- **THEN** окно «Изменение операции» показывает записанную операцию; после «Сохранить» операция с `5b1e…` одна

#### Scenario: Операцию удалили и записали снова
- **WHEN** операция `5b1e…` удалена на телефоне, и пользователь сохраняет окно с этим uuid
- **THEN** та же строка снова живая, с новыми полями; второй строки с `5b1e…` нет

### Requirement: Не больше одной операции на uuid
База телефона SHALL NOT содержать две операции с одним uuid. Вставка
операции, uuid которой уже есть, SHALL отклоняться, а не создавать вторую
строку. Перевод базы на эту схему SHALL сохранить одну строку на uuid, если
дубли уже были, а лишние пометить удалёнными.

#### Scenario: Двойное нажатие «Сохранить»
- **WHEN** пользователь дважды быстро нажал «Сохранить» в окне с uuid `5b1e…`
- **THEN** в базе одна операция с `5b1e…`

#### Scenario: Обновление приложения с дублями uuid
- **WHEN** в базе установленной версии две операции с одним uuid, и приложение обновляется
- **THEN** после обновления одна из них живая, вторая помечена удалённой, приложение запускается
