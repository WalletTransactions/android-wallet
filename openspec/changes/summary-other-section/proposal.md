## Why

Карточка итогов («На начало», «На конец», «Доход», «Расход», «Итог») обросла восемью дополнительными строками: «Капитал», «Всего с капиталом», «Мне должны», «Я должен», «Всего с долгами», «В капитал / из капитала», «В долг / из долга», «Курсовая разница». На узком экране (Huawei P20 Pro) они занимают больше места, чем сами итоги. Долги, в отличие от капитала, не прячутся вовсе, а выключатель «Капитал в итогах» прячет только часть строк и ломает единую картину.

## What Changes

- Все дополнительные строки сворачиваются в одну строку **«Прочее»** с суммой и кнопкой ▾ для раскрытия деталей.
- Сумма «Прочего» за период = `Итог − (Доход − Расход)`; это то, что сводит «Итог» с «Доход − Расход» (в капитал / из капитала, в долг / из долга и курсовая разница).
- В раскрытом виде «Прочее» показывает: изменение капитала (если было), «Капитал», изменение долгов (если было), «Мне должны», «Я должен», «Курсовая разница» (если не ноль), «Всего с капиталом и долгами».
- Новая настройка **«Раскрывать «Прочее» при открытии»** (по умолчанию выключена): включена — карточка открывается сразу в раскрытом виде, выключена — видна только сумма.
- Нажатие ▾ на экране меняет вид только на этом экране и **не меняет** настройку; при повторном открытии экрана вид снова берётся из настройки.
- **BREAKING (внутренне)**: настройка «Капитал в итогах» удаляется; блоки капитала и долгов теперь управляются только данными (есть активы / есть займы). Обратная совместимость со старым значением настройки не нужна.

## Capabilities

### New Capabilities
- `period-summary`: карточка итогов периода — строка «Прочее», раскрытие деталей, настройка начального вида.

### Modified Capabilities
- `capital-assets`: строки «Капитал» / «Всего с капиталом» и сверка с капиталом переезжают в детали «Прочего», условие «настройка „Капитал в итогах“» исчезает.
- `debts`: строки «Мне должны» / «Я должен» / «Всего с долгами» / «В долг / из долга» переезжают в детали «Прочего».

## Impact

- Код: `res/layout/view_period_summary.xml`, `Activities/BaseTabActivity.java` (`refreshSummaryCard`, `refreshCapitalRow`, `refreshDebtRows`, `refreshReconciliationRows`), `Activities/SettingsActivity.java`, `res/layout/activity_settings.xml`, `AppSettings.java`, строки `values/` и `values-ru/` (`strings_capital.xml`, `strings_debts.xml`).
- Экраны с карточкой: «Операции», «Кошельки», «Отчёты» (общий `view_period_summary`).
- Другие сервисы не затрагиваются: расчёт локальный, из SQLite.
- Документация: `docs/ARCHITECTURE.md` — если описывает карточку итогов.
