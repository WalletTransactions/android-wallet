## ADDED Requirements

### Requirement: Недавние адреса сервера
Телефон SHALL запоминать до трёх последних адресов сервера, на которых
вход завершился успешно (по паролю, при регистрации или через Google), с
завершающим `/`. Повторный вход на тот же адрес SHALL поднимать его в начало
без дубля. Сохранение адреса без входа список не меняет. Список хранится только
на устройстве и в синк не уходит.

#### Scenario: Вход запоминает адрес
- **WHEN** пользователь сохранил адрес `https://192.168.1.100:8444` и вошёл по паролю
- **THEN** в диалоге «Адрес сервера» под полем показан `https://192.168.1.100:8444/`

#### Scenario: Не больше трёх, новые первыми
- **WHEN** пользователь успешно входил на адресах A, B, C и затем D
- **THEN** диалог показывает D, C, B

#### Scenario: Повторный вход без дубля
- **WHEN** пользователь входил на A, затем на B, затем снова на A
- **THEN** диалог показывает A, B

#### Scenario: Неудачный вход не запоминается
- **WHEN** пользователь сохранил адрес, по которому никто не отвечает, и попытка входа не удалась
- **THEN** этого адреса нет среди недавних

### Requirement: Выбор недавнего адреса
Диалог «Адрес сервера» SHALL показывать недавние адреса под полем ввода, самый
новый первым, с подписью «Недавние адреса». Нажатие на адрес SHALL подставлять
его в поле, сохраняет кнопка «Сохранить». Без успешных входов в диалоге только
поле ввода.

#### Scenario: Выбор из списка
- **WHEN** пользователь нажимает недавний адрес в диалоге, затем «Сохранить»
- **THEN** адрес сервера меняется на выбранный

#### Scenario: Истории нет
- **WHEN** на телефоне ещё не было успешного входа
- **THEN** диалог «Адрес сервера» содержит только поле ввода
