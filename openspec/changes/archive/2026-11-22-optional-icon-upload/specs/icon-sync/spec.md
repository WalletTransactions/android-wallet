# Spec Delta

## MODIFIED Requirements

### Requirement: Иконки только скачиваются
Проход синка SHALL по умолчанию NOT отправлять иконки: в `POST /sync/push` нет
таблицы `icon`, а `POST /sync/blobs` и `HEAD /sync/blobs/{sha256}` (wallet-api)
не вызываются. Исключение — включённая настройка «Отправлять свои иконки на
сервер» при разрешающем флаге сервера (см. `icon-upload`). Загрузка новых и
изменённых иконок через `GET /sync/pull` и `GET /sync/blobs/{sha256}` SHALL
работать как раньше.

#### Scenario: Добавлена своя иконка
- **WHEN** пользователь добавил иконку из галереи, настройка отправки выключена (по умолчанию), и он запустил синк
- **THEN** ни одного запроса к `/sync/blobs` нет, в теле push нет `icon`

#### Scenario: Добавлена своя иконка, отправка включена
- **WHEN** пользователь добавил иконку, настройка включена и сервер разрешает, он запустил синк
- **THEN** иконка загружена через `/sync/blobs`, в теле push есть `icon`, после приёма у иконки `origin = 0`

#### Scenario: Администратор добавил иконку
- **WHEN** на сайте создана общая иконка, и телефон проходит синк
- **THEN** иконка появляется в списке иконок телефона с картинкой с сервера
