# Spec Delta

## ADDED Requirements

### Requirement: Вход в маршруты пересчёта
Экран «Курсы валют» SHALL содержать вход «Маршруты» в экран маршрутов; удаление
пары SHALL снимать использующие её маршруты (спека `currency-routes`).

#### Scenario: Переход
- **WHEN** пользователь нажимает «Маршруты» на экране «Курсы валют»
- **THEN** открывается экран «Маршруты пересчёта»
