# Spec Delta

## MODIFIED Requirements

### Requirement: Как настроить повторяющуюся операцию
Регулярный платёж (аренда, подписка, зарплата) можно задать один раз: «Ещё» → «Шаблоны операций» → «+ Добавить шаблон». В форме выбирают «Расход», «Доход» или «Перевод», статью и «Кошелёк», «Общую сумму», период в поле «Повторять» (ежедневно, еженедельно, ежемесячно, ежегодно) и дату начала «С какой даты»; конец необязателен, по умолчанию «Всегда». Приложение само создаст операции по расписанию; повтор можно выключить переключателем «Повтор включён». Если дата начала в прошлом, приложение спросит в диалоге «Пропущенные повторы», создать ли пропущенные операции. Справка SHALL отвечать на вопросы о регулярных платежах так.

#### Scenario: Ежемесячная аренда
- **WHEN** пользователь спрашивает «Как сделать, чтобы аренда записывалась каждый месяц?»
- **THEN** ответ ведёт на «Ещё» → «Шаблоны операций» → «+ Добавить шаблон», называет «Повторять» → «Ежемесячно» и «Сохранить»

#### Scenario: Остановить повтор
- **WHEN** пользователь спрашивает, как остановить регулярную операцию
- **THEN** ответ: открыть шаблон и выключить «Повтор включён», выбрать «Повторять» → «Не повторять» или удалить шаблон

## ADDED Requirements

### Requirement: Как завести шаблон снятия наличных с комиссией
Типовую операцию из нескольких проводок, например снятие наличных с картой и комиссией, можно завести один раз: «Ещё» → «Шаблоны операций» → «+ Добавить шаблон», вид «Перевод», счета «Откуда» и «Куда», переключатель «Комиссия за перевод» и «Размер комиссии» («Фикс» или «% от суммы»). Запускают шаблон тапом по нему в списке: вводят «Общую сумму» (она включает комиссию) и нажимают «Сохранить». Справка SHALL отвечать на вопросы о повторяющемся вводе нескольких проводок так.

#### Scenario: Снятие наличных
- **WHEN** пользователь спрашивает «Как быстро вносить снятие наличных с комиссией?»
- **THEN** ответ ведёт на «Ещё» → «Шаблоны операций» → «+ Добавить шаблон», называет «Комиссия за перевод», тап по шаблону в списке, «Общая сумма» и «Сохранить»
