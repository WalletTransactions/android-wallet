# Spec Delta

## MODIFIED Requirements

### Requirement: Пункты таба «Ещё»
Таб «Ещё» нижней панели SHALL показывать экран «Ещё» с пунктами в порядке:
«Кошельки и категории» (справочник счетов с правкой по тапу, см.
`account-screens`), «Долги» (экран долгов, см. `debts`), «Шаблоны операций»
(список шаблонов, в том числе повторяющихся, см. `operation-templates`), «ИИ»
(см. `ai-expense-entry`), «Вопрос по
приложению» (см. `docs-assistant`; пункта нет, пока сервис ответов не
подтвердил доступность), «Интеграции» (см. `server-account`), «Открыть
веб-версию», «Курсы валют» (список валютных пар), «Иконки и категории»
(управление иконками), «Настройки». Нижняя панель и её кнопка «+» на экране те
же, что на остальных табах; шапки с периодом и фильтром нет. Пункты, кроме
«ИИ» и «Вопрос по приложению», всегда доступны, в том числе без входа и без
сети.

#### Scenario: Без входа и без сети
- **WHEN** пользователь не входил в аккаунт, сети нет, и он открывает таб «Ещё»
- **THEN** все пункты, кроме «ИИ», открывают свои экраны, пункта «Вопрос по приложению» нет

#### Scenario: Курсы валют
- **WHEN** пользователь нажимает «Курсы валют»
- **THEN** открывается список валютных пар

#### Scenario: Шаблоны операций
- **WHEN** пользователь нажимает «Шаблоны операций»
- **THEN** открывается список шаблонов, пункта «Повторяющиеся операции» в «Ещё» нет
