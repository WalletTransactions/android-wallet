# Spec Delta

## MODIFIED Requirements

### Requirement: Экран «Настройки»
Пункт «Настройки» SHALL открывать экран «Настройки» с разделами
«ОФОРМЛЕНИЕ» (тема, «Язык» — см. `ui-language`), «ВАЛЮТА» («Валюта
эквивалента», «Капитал в итогах»), «ВВОД ОПЕРАЦИЙ» («Сразу открывать
клавиатуру поиска», «Сортировка кошельков», «Сортировка категорий»),
«СПРАВОЧНИК» («Панель фильтров: Кошельки», «Панель фильтров: Категории»),
«БЕЗОПАСНОСТЬ» («Код доступа», «Сменить код», «Блокировать», «Скрывать в
недавних», «Вход по отпечатку» — см. `app-lock`), «УВЕДОМЛЕНИЯ»
(«Напоминание вносить операции» — см. `reminders`), «ДАННЫЕ» и «О
ПРИЛОЖЕНИИ». Стрелка «назад» закрывает экран. Все настройки хранятся только на
телефоне и SHALL NOT синхронизироваться с сервером.

#### Scenario: Настройки на другом телефоне
- **WHEN** пользователь выбрал тёмную тему на одном телефоне и вошёл тем же аккаунтом на другом
- **THEN** на другом телефоне тема не меняется

#### Scenario: Раздел «СПРАВОЧНИК»
- **WHEN** пользователь открывает «Настройки»
- **THEN** между «ВВОД ОПЕРАЦИЙ» и «БЕЗОПАСНОСТЬ» есть раздел «СПРАВОЧНИК» с двумя переключателями «Панель фильтров: Кошельки» и «Панель фильтров: Категории»

## ADDED Requirements

### Requirement: Панель фильтров в справочнике
Переключатели «Панель фильтров: Кошельки» и «Панель фильтров: Категории» с подписью
«развёрнута при открытии справочника» SHALL по умолчанию быть выключены. Каждый
задаёт исходное состояние панели «Фильтры» справочника «Кошельки и категории» на
своей вкладке (`account-screens`, «Исходное состояние панели фильтров»). Значения
сохраняются на телефоне, не синхронизируются с сервером и не входят в JSON-экспорт.

#### Scenario: По умолчанию
- **WHEN** пользователь впервые открывает «Настройки»
- **THEN** оба переключателя панели фильтров выключены

#### Scenario: Включение сохраняется
- **WHEN** пользователь включает «Панель фильтров: Категории» и перезапускает приложение
- **THEN** переключатель остаётся включённым, а при открытии справочника панель на вкладке «Категории» развёрнута

#### Scenario: Переключатели независимы
- **WHEN** пользователь включает «Панель фильтров: Кошельки»
- **THEN** «Панель фильтров: Категории» остаётся выключенным

#### Scenario: Экспорт
- **WHEN** пользователь включил оба переключателя и делает JSON-экспорт
- **THEN** в файле нет значений настроек панели
