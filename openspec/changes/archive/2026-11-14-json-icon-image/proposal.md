# Proposal

## Why

Файловый JSON называет иконку счёта только по имени (`"icon": "Groceries"`):
если иконки с таким именем на телефоне нет, счёт получает `unknown`. Передать
свою картинку категории или кошелька файлом нельзя, поэтому после переезда
(другой телефон, чужая выгрузка, конвертер) своя графика теряется, а экспорт
молча отбрасывает картинки своих иконок.

## What Changes

- Элемент `accounts` получает необязательное поле `icon_image` — base64
  картинки (PNG/JPEG/WEBP, допустим префикс `data:...;base64,`). Импорт
  заводит свою иконку (`origin=local`, тип «категория») и ставит её счёту;
  имя иконки — `icon`, а без него (или при `unknown`) — имя счёта. Любой размер
  приводится к 256×256: не квадрат обрезается по центру, результат — WEBP, как у
  иконок из редактора.
- Иконка с таким именем уже есть: своя получает новую картинку, серверная
  (только просмотр) не меняется, счёт ссылается на неё.
- Битая картинка (не base64, не картинка, строка длиннее 1,5 млн символов) **не
  мешает счёту**: он импортируется как раньше — с иконкой по имени `icon`, а если
  такой нет, с `unknown`. Элемент не пропускается, ошибки в отчёте нет.
- Экспорт пишет `icon_image` у счетов со своей иконкой (серверные — только по
  имени), так что «экспорт → импорт» сохраняет картинки.
- Файл без `icon_image` импортируется как раньше.

**Не входит:** картинки у валют и контрагентов; тип иконки «флаг»; отдельный
раздел `icons`; конвертер Money Lover (в выгрузке картинок нет).

## Capabilities

### New Capabilities
Нет.

### Modified Capabilities
- `data-import`: поле `icon_image` у счёта, нормализация, поведение при битой
  картинке и при уже существующей иконке.
- `data-export`: `icon_image` у счетов со своей иконкой.

## Impact

- `Data/WalletImportData.java` (`decodeIconImage`, `putOwnIcon`,
  `ParseAndInsertJsonAccount`), `Data/WalletExportData.java`.
- Строки «Формат» импорта (`strings_import.xml`, ru/en), `_comment` экспорта.
- Тест `ImportIconImageJsonTest`. Серверу и синку ничего не меняется: свои
  иконки на сервер не уходят (`origin=local`), в push вместо них иконка-заместитель.
