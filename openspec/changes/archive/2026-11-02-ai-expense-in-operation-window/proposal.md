# Proposal

## Why

Трата своими словами (`ai-expense-entry`) правится в отдельной карточке на
экране «ИИ», которая повторяет окно операции хуже: нет клавиатуры суммы,
перевода, комиссии, выбора через привычный пикер. Импорт выписки
(`add-ai-statement-import`) уже правит строки в стандартном окне операции —
свободная форма должна вести себя так же, чтобы у пользователя было одно окно
правки.

## What Changes

- **Черновик открывается в окне «Новая операция»** с суммой, датой, кошельком,
  категорией и комментарием из разбора. Карточка на экране «ИИ» убирается.
- **Подсказки resolver переезжают в окно**: строка «Подсказка ИИ: …» над
  полями («Какая категория?», «В тексте EUR, а «Тинькофф» в RUB», «Нет
  кошелька в USD»), кандидаты `ask` идут первыми в пикерах кошелька и
  категории.
- **Проверки — как у ручного ввода**: окно проверяет сумму и выбор счетов
  само. Отдельные проверки карточки (точность, дата в будущем) уходят.
- **«Кошелёк пропал»** остаётся на экране «ИИ»: блок ошибки с деталями,
  «Синхронизировать и повторить» и вместо «Выбрать другой» — «Открыть
  операцию» (окно с пустым полем, выбор там).
- **Возврат из окна**: сохранено — «Записано: …», поле очищается, кошелёк
  запоминается; закрыто без сохранения — «Разбор не записан» и «Открыть
  снова» без нового запроса к ИИ.
- Окно операции возвращает id сохранённой операции, принимает приоритетные
  счета для пикеров и текст подсказки.

### Modified Capabilities
- `ai-expense-entry`: карточка черновика заменяется окном операции —
  меняются требования «Карточка черновика», «Вопрос resolver — выбор в
  карточке», «Отказ resolver по кошельку», «Кошелёк или категория пропали с
  телефона», «Детали ошибки «пропал»», «Синхронизировать и повторить»,
  «Запись операции»; «Проверки перед записью» удаляется, вместо него —
  «Проверки в окне операции».

## Impact

- Код: `AiActivity` и `activity_ai.xml` (карточка удаляется, блок ошибки и
  строка результата остаются), `TransactionActivity` (extras подсказки и
  приоритетных счетов, результат с id сохранённой операции),
  `AccountPickerActivity` (приоритетные счета первыми), `ai/AiTexts`
  (тексты подсказки), README и `docs/ARCHITECTURE.md`.
- Пересечение с `add-ai-statement-import`: тот же пикер получает подсказку
  категории (задача 1.4). Механизм приоритетных счетов — общий, делается
  в том change, который реализуется первым.
- Серверы: правок нет.
