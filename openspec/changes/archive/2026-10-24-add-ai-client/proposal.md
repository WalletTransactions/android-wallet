# Proposal

## Why

Трата своими словами через wallet-ai уже работает в вебе и в боте, а на телефоне,
где траты вносятся чаще всего, её нет. Сервер к этому готов: пользовательский
токен Android уже несёт `aud` `wallet-ai` и `scope` `ai:use`, gateway проксирует
`/api/ai/*`. Это закрывает открытый вопрос «Android» из
`org/docs/TODO_wallet_ai.md`. Ответ: да, через `wallet-ai`.

## What Changes

- Новый экран «ИИ» (вход из «Ещё»): текст траты → задание `parse_expense` →
  карточка черновика → запись операции. Поведение карточки повторяет веб
  (`wallet-web` spec `ai-expense-entry`): found/ask/reject resolver, проверки,
  «Заполнить вручную». Запись идёт локально через `WalletDbCRUD`, на сервер её
  отправляет обычный синк.
- Ввод текста ещё двумя путями (п. 1a):
  - «Поделиться» текстом из другого приложения (`ACTION_SEND`, `text/plain`)
    открывает экран «ИИ» с этим текстом;
  - голосовой ввод через системное распознавание речи.
- Перед созданием задания приложение делает предварительный синк (push + pull):
  так справочник кошельков и категорий на сервере, по которому решает resolver,
  совпадает с телефоном.
- Если кошелька или категории из черновика нет на телефоне (не найден, удалён,
  в архиве), выводится ошибка с деталями. Карточка остаётся, запись
  блокируется, рядом кнопки «Синхронизировать и повторить» и «Выбрать другой».
- Синк становится однопроходным для всего процесса: если `SyncWorker`, кнопка
  «Синхронизировать сейчас» и экран «ИИ» запускают его одновременно, второй вызов
  дожидается уже идущего прохода, а не запускает параллельный.
- Пункт «ИИ» доступен только при входе в аккаунт и `GET /api/ai/status` с
  `enabled: true` и `parse_expense` в `features`; иначе неактивен с причиной.

Вне охвата: импорт выписки (`/api/ai/imports`) и уведомления банка по шаблону
(`TODO_statement_import.md` §11.5). Это отдельные change.

## Capabilities

### New Capabilities
- `ai-expense-entry`: экран «ИИ» в Android — ввод текста (поле, «Поделиться»,
  голос), задание `parse_expense`, предварительный синк, карточка черновика,
  сверка с локальным справочником и ошибка «кошелёк пропал», локальная запись.
- `sync-run`: проход синка (refresh → push → pull) и его единственность в
  процессе для всех вызывающих (воркер, кнопка, экран «ИИ»).

## Impact

- Код: новая `Activities/AiActivity` (+ layout, строки), клиент
  `sync/AiApiClient` (jobs, status), `SyncRunner` (замок и ожидание идущего
  прохода), `MoreActivity` (пункт «ИИ»), `AndroidManifest.xml` (intent-filter
  `ACTION_SEND`), `docs/ARCHITECTURE.md`.
- Серверы: правок нет. google-auth (scope/aud уже выдаются), wallet-gateway
  (маршрут уже есть) и wallet-ai (`parse_expense`, `status`) используются по
  текущему контракту `wallet-ai/openapi.yaml`.
- Зависимости: новых библиотек нет. Распознавание речи — системный
  `RecognizerIntent`, без разрешения `RECORD_AUDIO`.
- Нагрузка на GPU: только интерактивные задания по нажатию, как у веба.
