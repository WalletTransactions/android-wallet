# Design

## Context

Все запросы идут через общий OkHttp-клиент (`HttpClients`). Он бросает `IOException`
разных подтипов, и до сих пор их обрабатывали одинаково. `AuthSession.ensureFresh`
возвращает enum `Outcome` без причины. Синк, Telegram и ИИ различают только
`NETWORK_ERROR`.

## Goals / Non-Goals

**Goals:** пользователь по тексту ошибки понимает, что исправить: установить CA,
поправить адрес, проверить сеть или дату.

**Non-Goals:** проверка сервера по кнопке, установка CA из приложения (Android требует,
чтобы пользователь сделал это сам в настройках), изменение текстов экрана «ИИ».

## Decisions

### D1. Причина определяется по типу исключения и цепочке причин

На Android ошибка доверия приходит как `SSLHandshakeException` ←
`CertificateException` ← `CertPathValidatorException`, поэтому смотреть нужно всю цепочку
`getCause()`. Порядок проверок важен, потому что всё TLS — подвиды `SSLException`:

1. `SSLPeerUnverifiedException` — имя не совпадает;
2. в цепочке `CertificateExpiredException` / `CertificateNotYetValidException` — срок;
3. в цепочке `CertPathValidatorException` — не доверен;
4. прочий `SSLException` — ошибка TLS (например, https на порт без TLS);
5. `UnknownHostException`, `SocketTimeoutException`, `ConnectException` /
   `NoRouteToHostException`;
6. прочее — «Сервер недоступен: <сообщение>», как раньше.

Разбор текста сообщения исключения отклонён: он зависит от версии Conscrypt и языка.

### D2. Причина из `AuthSession` — через поле, а не через новый тип результата

`ensureFresh` вызывают синк, Telegram, ИИ и справка. Если менять тип результата,
пришлось бы трогать их все. Вместо этого последнее `IOException` хранится в `volatile`
поле. Оно сбрасывается в начале каждого вызова, а сам метод `synchronized`, поэтому
причина относится к последнему обновлению сессии. Если ошибкой был HTTP-код, а не
сбой соединения, поле пустое, и вызывающий показывает прежний общий текст.

### D3. Два варианта текста

Полный текст (с подсказкой) — для диалога синка и экрана входа. Короткий
(«Ошибка сертификата» / «Сервер недоступен») — для строки «Подключение к Telegram»,
где длинный текст не помещается.

## Другие сервисы

Правки в google-auth, wallet-api, wallet-gateway не нужны.

## Без сети

Поведение без сети не меняется: тот же исход «нет сети», токены не трогаются,
фоновый синк повторяется позже. Меняется только текст причины.
