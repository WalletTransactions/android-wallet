# Proposal

## Why

Приложение рассчитано на новых людей (см. `new-user-default-set`), а
интерфейс есть только на русском, и он почти не вынесен в ресурсы: в
`res/values/strings.xml` 36 строк, `getString(R.string…)` в Java не
вызывается ни разу. Тексты зашиты в ~295 атрибутах `text`/`hint`/`title` в
55 layout/menu и в ~640 строках Java (71 файл), окончания у чисел
подбираются вручную. Без выноса строк перевод невозможен, а каждый новый
экран добавляет ещё зашитый текст.

## What Changes

- Все тексты интерфейса — экраны, диалоги, тосты, уведомления, журнал
  синка, фиксированные тексты экрана «ИИ» — выносятся в ресурсы; склейки
  строк — в форматные строки, окончания у чисел — в plurals.
- Полный английский перевод.
- Язык интерфейса — по языку телефона: русский для русского, английский
  для любого другого. На Android 13+ язык приложения можно выбрать в
  настройках системы.
- **BREAKING (вид):** системные категории показываются на языке
  интерфейса: «Перевод» и «Комиссия за перевод» на русском, `Transfer` и
  `Transfer commission` на английском. Хранимые и отправляемые имена не
  меняются.
- Проверка в CI, что в Java и layout не появляются новые зашитые тексты.

- `ui-language`: язык интерфейса — выбор, полнота перевода, склонения,
  показ системных категорий, что не переводится.

## Impact

- `app/src/main/res/values/strings.xml` и новый `values-en/` (или
  `values-ru/` после смены базового языка, см. design), `res/xml/locales_config.xml`,
  `AndroidManifest.xml` (`android:localeConfig`).
- Все `Activities/*`, `sync/SyncEngine.java`, `sync/SyncLog.java`,
  `sync/SyncRunner.java`, `ai/AiTexts.java`, `reminder/ReminderWorker.java`,
  `security/BiometricErrors.java`, `Data/Wallet*Data.java` и др. — по
  экранам.
- Тесты: `src/test/resources/robolectric.properties` (язык тестов),
  тесты, проверяющие тексты.
- CI: скрипт проверки зашитых текстов в `ci/`.
- Сервер не меняется. Тексты, приходящие с сервера (ошибки wallet-api,
  ответы wallet-ai), показываются как есть — отдельная работа в сервисах.
- wallet-web и wallet-telegram — отдельные change в своих репозиториях.
