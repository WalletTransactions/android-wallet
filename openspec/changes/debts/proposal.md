# Proposal

## Why

Деньги, данные в долг, сейчас можно провести только расходом на категорию:
они смешиваются с тратами, а остаток «кто сколько должен» нигде не виден
(issue [.github-private#10](https://github.com/WalletTransactions/.github-private/issues/10),
разбор, варианты и ответы на вопросы — в комментариях к нему). Принят
вариант B: долг — кошелёк контрагента с признаком `account_debt`; знак его
баланса — направление долга; деньги идут обычными переводами, поэтому доход
и расход не искажаются.

Это клиентская часть набора `debts` (парные changes: `wallet-api` — схема,
синк и SQL-функции; `wallet-report` — отчёты и эндпоинт долгов;
`wallet-telegram` — убрать долговые кошельки из выбора).

## What Changes

- **Контрагенты.** Новая синхронизируемая таблица `counterparty` (имя,
  комментарий, иконка, архив) и экран управления: создать, переименовать,
  архивировать, удалить (только без живых долгов). Имя уникально без учёта
  регистра. Контрагенты общие для всех участников леджера.
- **Долговой кошелёк.** Новая синхронизируемая таблица `account_debt`
  (расширение кошелька, uuid = uuid счёта): контрагент, комментарий, срок
  возврата. Один заём — один кошелёк; у контрагента их может быть несколько,
  в том числе в одной валюте. Баланс «+» — мне должны, «−» — я должен.
- **Действия при вводе операции.** В выборе категории — «Дать в долг»,
  «Взять в долг», «Вернуть». Выбор контрагента → выбор займа (существующий
  кошелёк или «Новый заём») → обычный перевод между вашим кошельком и
  долговым. «Вернуть» подставляет направление по знаку баланса. Долговые
  кошельки в обычных пикерах кошелька не предлагаются.
- **Подпись в ленте.** Перевод с долговым кошельком в ленте подписан «Дал в
  долг» / «Взял в долг» / «Вернул долг» / «Мне вернули» — подпись вычисляется
  по накопленному балансу, в операции не хранится.
- **Экран «Долги».** Контрагенты с займами: остаток по каждой валюте, срок
  возврата, просрочка; итоги «Мне должны» / «Я должен» в эквиваленте.
  Карточка займа: операции, срок, комментарий, действия «Вернуть» и
  «Простить».
- **Прощение долга.** Остаток займа списывается проводкой «долговой кошелёк
  ↔ категория» (по умолчанию обычная категория «Списание долгов»), на выбранную
  дату; в расход или доход — по знаку.
- **Переплата.** Возврат больше остатка разрешён с предупреждением: знак
  баланса меняется на противоположный.
- **Итоги.** Карточка периода и таб «Кошельки»: ликвидные итоги без долговых
  кошельков; отдельные строки «Мне должны», «Я должен», «Всего с долгами»,
  строка «В долг / из долга» в сверке периода.
- **Контакты телефона.** Контрагента можно выбрать из контактов системным
  выбором контакта; ключ контакта хранится только на этом телефоне
  (`counterparty_contact`, не синхронизируется), на сервер уходит имя. Не
  получилось или отказались — имя вводится текстом.
- **Синк.** `counterparty` и `account_debt` отправляются и загружаются;
  после обновления приложения поток ledger один раз перечитывается с начала.
- **ИИ-карточка и импорт выписок.** Долговые кошельки не предлагаются как
  «кошелёк трата».

**Не входит:** проценты, ставка, график платежей, напоминания; распределение
возвратов по займам (пользователь сам выбирает заём); запрет «кошелёк и
актив, и долг» на сервере (клиент не предлагает); подсказки «это долг?» в
ИИ-карточке, импорте выписок и боте; механизм минимальной версии клиента.

## Capabilities

### New Capabilities
- `debts`: контрагенты, долговые кошельки, действия «Дать / Взять /
  Вернуть», экран «Долги», прощение, переплата, итоги, связь с контактами
  телефона.

### Modified Capabilities
- `sync-run`: однократная повторная загрузка потока ledger с начала после
  обновления, вводящего новые синхронизируемые таблицы.

## Impact

- **Схема телефона:** новые таблицы `counterparty`, `account_debt`
  (триггеры dirty, индексы uuid) и локальная `counterparty_contact`; шаг БД
  — следующая свободная версия на момент реализации (сейчас в коде
  `DATABASE_VERSION = 90`).
- **Код:** `Data/WalletDbHelper`, `WalletDbLoader`, `WalletDbCRUD`,
  `sync/SyncEngine`, `AccountPickerActivity`, `TransactionActivity`,
  `AccountActivity`, `BaseTabActivity` (карточка периода), новые экраны
  «Долги», «Контрагенты», карточка займа, диалог прощения; строки ru/en.
- **Документация:** `docs/ARCHITECTURE.md` (схема, миграции, синк, расчёт
  балансов).
- **wallet-api:** парный change; без него push `counterparty` и
  `account_debt` молча теряется — порядок выката: сервер раньше APK.
- **Разрешения:** новых не добавляется (design D7).
