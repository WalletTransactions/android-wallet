# Spec Delta

## MODIFIED Requirements

### Requirement: Экран «Иконки и категории»
Пункт «Иконки и категории» на табе «Ещё» SHALL открывать экран «Иконки и
категории» со всеми живыми иконками телефона (без помеченных удалёнными),
сгруппированными по типу: «Категория» и «Флаг». Группа без иконок SHALL NOT
показываться. Иконки группы выводятся сеткой по 6 в ряд, только картинкой.
Нажатие на иконку открывает её диалог. Экран SHALL иметь стандартную раскладку
(`list-screen-layout`): вверху поле «Поиск по названию» — остаются иконки, в названии
которых встречается введённая строка как подстрока, без учёта регистра и пробелов по
краям; внизу всегда видимая кнопка «+ Иконка», открывающая диалог новой иконки. Группа без
подходящих иконок не показывается; если не подошла ни одна иконка, показано «Ничего не
найдено». Деление иконок на «свои» и «с сервера» и вид диалога иконки с
сервера описаны в `icon-sync`.

#### Scenario: Обе группы
- **WHEN** на телефоне есть иконки категорий и флаги, пользователь открывает «Ещё» → «Иконки и категории»
- **THEN** экран «Иконки и категории» показывает группы «Категория» и «Флаг», в каждой иконки по 6 в ряд

#### Scenario: Пустая группа
- **WHEN** на телефоне нет ни одной живой иконки типа «Флаг»
- **THEN** группы «Флаг» на экране нет

#### Scenario: Поиск по названию
- **WHEN** пользователь вводит «еда»
- **THEN** остаются иконки с «еда» в названии, группа без совпадений скрыта

#### Scenario: Ничего не найдено
- **WHEN** ни одна иконка не подходит под введённую строку
- **THEN** показано «Ничего не найдено», кнопка «+ Иконка» остаётся на месте

#### Scenario: Кнопка добавления всегда видна
- **WHEN** список иконок прокручен
- **THEN** кнопка «+ Иконка» видна внизу, её нажатие открывает диалог новой иконки
