# Proposal

## Why

Пользователь: «когда появляется окно добавления, проставленное по всем
пунктам, кнопка «Сохранить» неактивна — нужно любое изменение».

Черновик из ИИ (`ai-expense-entry`) открывает окно «Новая операция», где уже
заполнены сумма, кошелёк, категория, дата и комментарий. `TransactionActivity.onCreate`
после заполнения полей гасил «Сохранить» безусловно («Disable save until
something changes»), а слушатели полей, которые пересчитывают кнопку,
вешались уже после этого. Для правки существующей операции это верно —
изменений ещё нет; для новой операции, заполненной заранее, — нет: готовый
черновик нельзя было сохранить, не тронув поле.

## What Changes

- Начальное состояние «Сохранить» считается в `onCreate` тем же
  `updateSaveButton()`, что и при любой правке поля, — после снимка исходных
  значений правки. Новая операция с выбранными счетами и суммой сохраняется
  сразу; правка без изменений по-прежнему погашена; новая операция без суммы
  (или без счёта) — тоже.
- Robolectric-тест окна операции с теми же extras, что кладёт `AiActivity`.
