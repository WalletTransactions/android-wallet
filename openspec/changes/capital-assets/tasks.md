Номер шага БД ниже — `vN`: следующая свободная версия на момент реализации
(сейчас в коде `DATABASE_VERSION = 84`). Перед началом убедиться, что парный
change wallet-api (`account_asset` в синке, `system_kind = 3`) реализован хотя бы
на test — без него push признаков актива молча теряется (design, Risks).
