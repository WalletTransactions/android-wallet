# Spec Delta

## ADDED Requirements

### Requirement: Шаги маршрутов в синхронизации
Строки `currency_conversion` SHALL ездить в `/sync/push` и `/sync/pull` как шаги
маршрута леджера (`num` 1…3, пара, `is_reverse`); при pull строки со ссылкой на
ещё не пришедшие валюту или пару откладываются, как у остальных таблиц; шаги,
пришедшие по частям, не создают курса, пока цепочка не достроена. Контракт —
`openapi.yaml` wallet-api.

#### Scenario: Маршрут с сервера
- **WHEN** pull приносит два шага маршрута, созданного в вебе
- **THEN** на устройстве есть маршрут, эквивалент по нему считается
