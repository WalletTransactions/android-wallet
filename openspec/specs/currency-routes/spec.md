# currency-routes Specification

## Purpose
Маршруты пересчёта валют на устройстве: модель маршрута (цепочка шагов
`currency_conversion`), правила составного курса, экран управления. Серверные
правила — wallet-api (одноимённый change): приоритет и результат совпадают.

## Requirements

### Requirement: Модель маршрута
Маршрут `from → to` SHALL храниться строками `currency_conversion` с номерами
шагов `num` 1…3: каждая строка называет пару и направление шага
(`is_reverse`). Цепочка валидна, если `num` идут подряд с 1, шаги стыкуются,
концы совпадают с `from`/`to`; невалидная цепочка курса не даёт. Маршрут
двунаправленный, один живой маршрут на неупорядоченную пару валют, мягко
удаляется и синхронизируется как остальные справочники.

#### Scenario: Двунаправленность
- **WHEN** есть маршрут `BTC → EUR → RUB`
- **THEN** курс RUB→BTC равен `1 / курс BTC→RUB` на ту же дату

### Requirement: Составной курс и приоритеты
Курс валюты в валюту эквивалента SHALL браться в порядке: живой прямой курс
(в любую сторону) → явный маршрут → кросс через USD (`A → USD → B` по двум
прямым курсам; USD — валюта с `iso_code` = `USD`). Каждый шаг берёт последний
курс не позже даты независимо от других; составной курс меняется на дату
изменения любого шага. Нет курса у шага или цепочка оборвана — курса нет, 1:1
не применяется, явный валидный маршрут без курса блокирует USD.

#### Scenario: Маршрут
- **WHEN** BTC→EUR = 90 000, EUR→RUB = 100, маршрут `BTC → EUR → RUB`, эквивалент в RUB
- **THEN** кошелёк в BTC пересчитан по 9 000 000, итог без пометки «~»

#### Scenario: Кросс через USD
- **WHEN** есть пары BTC/USD (60 000) и USD/RUB (90), прямой пары и маршрута BTC→RUB нет
- **THEN** курс BTC→RUB равен 5 400 000

#### Scenario: Прямая пара приоритетнее
- **WHEN** есть пара BTC/RUB с курсом и маршрут `BTC → EUR → RUB`
- **THEN** используется прямая пара на любую дату

### Requirement: Каскад удаления пары
Мягкое удаление пары на устройстве SHALL мягко удалять и все маршруты, шаги
которых используют пару (целиком, все шаги), в той же операции.

#### Scenario: Пара в маршруте
- **WHEN** пользователь удаляет пару EUR/RUB, входящую в маршрут `BTC → EUR → RUB`
- **THEN** маршрут исчез из списка, остальные маршруты не тронуты

### Requirement: Экран «Маршруты пересчёта»
Из экрана «Курсы валют» SHALL открываться экран «Маршруты пересчёта» (по
спеке `list-screen-layout`): список маршрутов вида «BTC → EUR → RUB» с парами
шагов, пустое состояние «Маршрутов пока нет», кнопка «+ Маршрут» (путь из 3–4
валют: «Из», «Через», «В»). Проверки: все валюты выбраны, различны, такого
маршрута (в любом порядке) нет, для каждого шага есть пара — иначе ошибка в
форме. Удаление маршрута — с подтверждением, курсы и пары не меняются. Все
строки — в `values` и `values-ru`.

#### Scenario: Создание
- **WHEN** есть пары BTC/EUR и EUR/RUB, выбран путь BTC, EUR, RUB
- **THEN** маршрут добавлен, виден в списке, помечен к отправке на сервер

#### Scenario: Нет пары для шага
- **WHEN** для соседних валют пути нет пары
- **THEN** сохранение отклонено, в форме названа пара шага

#### Scenario: Дубль
- **WHEN** маршрут между BTC и RUB уже есть, выбран путь RUB, EUR, BTC
- **THEN** сохранение отклонено, в форме «Такой маршрут уже есть»
