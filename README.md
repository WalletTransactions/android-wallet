# android-wallet — «Посчитай и сбереги»

Android-приложение для учёта личных финансов: кошельки в разных валютах,
доходы и расходы по категориям, переводы, повторяющиеся операции, отчёты
и курсы валют. Работает офлайн на локальной SQLite; при желании
синхронизируется с собственным сервером WalletTransactions.

## Возможности

- **Операции** — доходы, расходы, переводы между кошельками (в т.ч.
  валютные, с комиссией), фильтр по периоду, категориям и кошелькам.
- **Кошельки** — счета в любых валютах, остатки и эквивалент в выбранной
  валюте.
- **Отчёты** — доходы и расходы по категориям за период.
- **Повторяющиеся операции** — правила с расписанием, включаются и
  выключаются одним переключателем.
- **Курсы валют** — валютные пары, история курсов и график; загрузка из
  Frankfurter (ECB), ЦБ РФ и Yahoo Finance.
- **Иконки** — свои иконки категорий и кошельков с кадрированием.
- **Импорт / экспорт** — JSON-формат всей базы (тот же, что понимает импорт
  из Money Lover).
- **Синхронизация** — вход через Google (Credential Manager), push/pull
  изменений с сервером, фоновое автоподключение через WorkManager.
- **ИИ** — трата своими словами («вчера такси 450 с тинькоффа»): текстом,
  голосом или через «Поделиться» из другого приложения; разбирает сервер
  (wallet-ai), записывает пользователь. См. «Экран «ИИ»» ниже.

Нижняя навигация: **Операции · Кошельки · Отчёт · Ещё**.

## Сборка и запуск

Нужны JDK 17 и Android SDK (platform 34, build-tools 30.0.3). Путь к SDK —
в `local.properties` (`sdk.dir=...`), файл в git не хранится.

```bash
./gradlew assembleDebug          # APK: app/build/outputs/apk/debug/
./deploy-debug.sh [serial]       # собрать и поставить на устройство через adb
```

`versionCode` растёт автоматически при каждой сборке (`app/version.properties`),
`versionName` — `1.0.<code>`; версия и время сборки видны в «Настройки → О приложении».

## Тесты

./gradlew :app:testDebugUnitTest     # локально

## Синхронизация с сервером

Приложение полностью работает без сервера. Для синхронизации: «Ещё →
Синхронизация» — указать адрес сервера (по умолчанию `http://localhost:8090/`)
и связать аккаунт через Google.

Поток: `POST /auth/nonce` → Credential Manager (Google ID token) →
`POST /auth/google/mobile` → пара access/refresh-токенов → `POST /sync/push` /
`pull`. На текущем этапе сервер доступен только в LAN и без TLS, поэтому
в манифесте включён `usesCleartextTraffic`.

Серверная часть (wallet-api, google-auth и др.) — в соседних репозиториях
организации [WalletTransactions](https://github.com/WalletTransactions).

## Экран «ИИ»

«Ещё → ИИ» — трата своими словами через сервис wallet-ai (контракт —
`wallet-ai/openapi.yaml`, `/api/ai/*` через гейтвей). Пункт активен, только
если есть вход в аккаунт и сервер отвечает, что ИИ включён
(`GET /api/ai/status`); иначе под ним причина.

1. Текст вводится в поле (до 500 символов), надиктовывается кнопкой микрофона
   или приходит через «Поделиться» (`text/plain`) из другого приложения —
   например, сообщение банка из Viber. Разбор сам не запускается: текст можно
   поправить.
2. «Разобрать» сначала синхронизирует телефон с сервером (до 10 секунд), чтобы
   сервер выбирал кошелёк и категорию по тому же справочнику, что на телефоне.
   Не успел или не удался синк — разбор всё равно идёт, под полем
   предупреждение с причиной.
3. Ответ открывается в обычном окне «Новая операция»: сумма, кошелёк,
   категория, дата и комментарий из разбора, сверху — «Подсказка ИИ» (исходный
   текст и вопросы: «Какая категория?», «В тексте EUR, а кошелёк в RUB»).
   Варианты, которые предложил ИИ, стоят первыми в выборе кошелька и категории.
   Если выбранного сервером кошелька или категории нет на телефоне (не загружен,
   удалён, в архиве), окно сразу не открывается: экран «ИИ» показывает ошибку с
   деталями и кнопками «Синхронизировать и повторить» и «Открыть операцию».
4. «Сохранить» в окне записывает операцию в базу телефона, как ручной ввод; на
   сервер её отвезёт синк. Записать можно и без сети, если разбор уже получен.
   Закрыли окно без сохранения — «Открыть снова» вернёт тот же разбор без
   нового запроса к ИИ.

ИИ недоступен или не понял текст — «Заполнить вручную» открывает обычный экран
новой операции с текстом в комментарии.

Приватность: текст траты уходит на свой сервер (wallet-ai), в logcat
приложения он не пишется. Голос распознаёт системный сервис Android; если на
телефоне нет офлайн-пакета русского языка, запись может уйти в облако
распознавания (обычно Google).
